# 写作细则

## 文体与篇幅

作者的列传以现代中文编年叙述为主，混合史传用语、政治评论、经济与制度解释。可以使用“资本”“共和”“金融”“政治派系”等符合该时代的概念，不必为仿古删掉现代解释能力。也不要全篇改成文言，或把每一段写成演义场景。

2026年10月27日，作者针对李大钊稿进一步要求“更白话文一些”。后续尤其是近代人物，应将自然、清楚的现代叙述作为默认语气。史传感来自取舍、编年和因果，不来自文言词的密度。不要因为参考列传有“遂”“尔后”，就让叙述和对白都变得古奥；已获认可的早期人物文字则不必无故全改。

| 原稿偏紧或偏古的表达 | 更白话的处理 |
| --- | --- |
| 家中所给不足，以所得供学费 | 家里寄来的钱不够，靠这些收入补贴学费 |
| 始渐留意繁荣之下的生计 | 直接写他发现谁吃不饱、为什么欠债，再写调查或行动 |
| 受党友之托北赴河南 | 受党友委托北上河南 |
| 争请吴廷确认其辖地与军职 | 请求吴廷保住自己的地盘和官职 |
| 以号令难行为由 | 觉得代表会议妨碍指挥；标明这是军官的看法 |
| 是年秋，公社已难久守 | 这年秋天，公社已经很难继续守下去 |

白话化仍须保留制度对象和动作的准确性；“军职”可以按语境解释成官职，但不能把不同政权、军队和党派笼统写成“上面”“他们”。对白可以简洁有力，不必为显得口语化加入当代网络语。

中篇的特征是选择关键转折、让每段推动一段生涯。参考材料中，华康甫、顾宪成、江弗、左光斗等约五六百字，黎笋约八百余字；吴世霖修订稿因涵盖十个阶段及政治互动，约千余字。这些是密度参照，不是硬性字数配额。大纲较长时合并相邻环节，不能为凑短篇删去作者指定经历。

首段一般采用“姓名（字某）（生卒年）：身份、重要职衔或历史地位。籍贯与出身。”不确定的字号不必补，生卒年不必精确到日。正文按生涯展开，不给每一段加小标题。末段以死亡及直接影响收束，避免再附一段泛泛颂词。

## 段落怎么推进

一段解决一个生涯问题，常见组织方式如下，按内容选用，不能机械套用：

- **出身形成条件：** 家庭或地方提供了什么资源，又造成什么限制；这些条件怎样影响他后来的选择。
- **经历改变判断：** 先写见到的人与制度，继而写原有认识哪里不够，最后写改变了什么做法。
- **政治转折：** 谁需要解决什么问题，各方各有什么筹码，人物采取何种办法，谁因此获益或受损。
- **战争与治理：** 军队由谁组成、粮械由谁供给、命令怎样落实，再写胜败和战后秩序。
- **结局：** 决定性困境、最后行动、死亡及组织或制度的延续。不用“精神永存”代替具体影响。

一个自然段若只有“他深刻认识到……”“他更加坚定了……”而没有新的事实、行动或关系，应压缩或重写。

## 句子的职责

每句尽量承担一个主要职责；必要时以分句补出原因或后果。

| 职责 | 可操作的写法 | 避免 |
| --- | --- | --- |
| 定位 | “1706年六月，世霖与首辅史问梁共同策划灭明。”时间、行动者、共同责任一次交代 | 在开头堆满时代概述，让人物迟迟不出现 |
| 说明权力 | “世霖依靠吴氏旧部居中督战，又与各州转运使商定……”把本部兵力和协作对象分开 | “总督下令整顿全国军队”，把官衔当无限权限 |
| 补足动机 | “燕廷也为招纳明朝旧臣，将逼宫之事推作他的擅断。”具体目的解释具体说法 | 无事件支撑的“心怀天下”“深谋远虑” |
| 转折 | “虽然使地方稍定，各营占田役民的根本并未改变。”限定政绩的范围 | 前文写遍地崩溃，后文忽然“百姓安居乐业” |
| 延续 | “吴营仍由其族人统领。”把个人死亡接回制度 | 不知后事却宣称“从此开创全新时代” |

先保证主语和承接清楚，再求简洁。两个同姓人物同段出现时重复姓名或职衔；不要连续用“他”“其”造成歧义。政治结论可以明确，不能把角色个人判断写成全知的客观事实。

## 字词的力度

| 用词 | 使用条件 |
| --- | --- |
| “遂” | 前面的判断或事件直接导致后面的行动；仅表示过了一段时间时不用 |
| “因而／因此” | 确有因果。无法回答“怎么造成的”时改为并列或补中间环节 |
| “尔后／此后” | 延续前一个阶段；必要时加新的年份，防止跨十年仍无锚点 |
| “时／当时” | 引入人物行动所需的局势，不滥用“当是时”装饰 |
| “受命／奉命” | 有可识别的授权者；擅自行事不能用来淡化责任 |
| “议定／商定” | 多方协作，必须能识别商议双方与所议事项 |
| “控制／掌握” | 明确控制的是兵员、经费、运输、任命还是地方；不写笼统的“一切” |
| “许／保留／分给” | 显示交换条件、利益和让步，不仅给人物贴善恶标签 |
| “稍／渐／一时／尚” | 对效果作有依据的限制，防止局部成功被写成彻底解决 |
| “以……为……” | 可写评价，也可写安排；注意到底是谁作出的判断 |

多用能看见后果的动词：“核额给饷”“筹办会刊”“募集救济”“交还人口”“撤出伤员”。少用没有宾语和机制的“推动发展”“深化思想”“加强建设”。“一手缔造”“首次”“彻底”“奠定一切”等强词须有足够材料支持。

## 对话与人物评论

对白的入口是分歧、压力或误判。先交代谁为什么开口，再用一两句短言语暴露立场，随后写决定或代价。不要每段安排金句，也不要让所有人都像同一位评论家说话。

原参考例：“因此被张化民斥曰：‘以德报怨，何以报德？叶将军重情，而误国甚矣！’”其中“斥”标示旧友间的冲突；前半借熟语建立价值判断，后半将矛盾落在叶的情分与政治责任上。它有具体对象与前因，不能挪给任何人物。

吴世霖修订例：“诸将所争，不过田土。今日许其议立，来日便敢议废。”前文是史问梁提议诸镇联名请行废立，后文是吴请求由家营承担逼宫。话语让读者理解他为什么限制盟友的政治资格；这是吴的判断，不能据此断言所有燕将只有田产欲望。

可以让反对者、同僚、家属、工人说话，补出主人公看不到的代价。没有既有人物时，采用无名但身份明确的见证者，或新增角色；不要为一句对白编造庞大谱系。写现代革命者可用较直白的近代语气，不必人人“曰”“乎”“矣”。

对白可原创、化用或引用。原创不得标成现实原话；化用须在说明中列来源与改动；原引核对原文、年代和说话人。正文不必每句加“虚构”，在依据中集中说明即可。引用现实人物时仍须判断该世界线是否具备同样的经历与观念。

## 时间与标点

- 关键节点写公历年份；作者指定“1706年六月”“1912年八月七日”就保留其形式。原稿同时使用“西元”“西历”和数字年份，选一种适合本篇的写法，不宣称全项目只有一种格式。
- 早年、青年、数年后可承担材料不足的阶段；不要填满虚构的精确年月日。“同年”必须有近邻的明确年份，“五个月后”须有起算事件。
- 月数推算在说明中注明推算口径，允许古代叙事的约数；不能把算术结果伪装成原文记载。
- 作者指定1912年的事件名为“辛亥革命”，不得按现实干支擅改为1911年或“壬子革命”。
- 生卒与战争区间用统一连接号；中文正文用中文引号，刊物与文献用书名号。多层括注、感叹号和破折号只在确有叙事作用时使用。

## 可重复的改写步骤

原句：“他接触工人，受到触动，思想逐渐进步。”

先补对象：“他为印工抄写欠薪呈词，才知道厂中停工数日，工人家中便无粮可炊。”再补判断与行动：“此后筹办会刊，便主张先筹救济，再议停工。”两句把经历和后来的组织方法相接；具体行业、呈词和安排若属补写，进入创作说明。

原句：“他忠于燕王，整顿军队，平定叛乱。”

先辨权力：哪些是家军，哪些是盟营；再辨资源：粮械、赏格由谁掌握；最后写个人选择：维护宗族还是牺牲亲属利益。没有这些中间环节，换几个古雅词也不会得到作者的文风。
