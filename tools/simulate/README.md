# 按脚本逐月模拟：估算概率、时间和数值

> 何时读：要估一条日志链、一套倾向或一组数值在 AI 与玩家手里各会怎样，或作者给了目标分布、要你调参。不必读：一次性的确定性对照（直接算或写小检查）。

这不是通用模拟器：每个内容各写一个，放在该任务的工作台报告目录 `reports/<日期>-<主题>/sim/`，规则只覆盖这一个内容。

## 做法

1. **照已部署的脚本逐月建模。** 每条规则在脚本开头注明出处文件；模拟的推进顺序与引擎一致（事件、按钮、来源结算、门槛判断）。引擎里不知道的东西单独标成假设，例如 AI 多久评估一次按钮的 `ai_chance`（按每周一次折算成月概率）。
2. **AI 与玩家分开。** AI 按脚本里的 `ai_chance` 和事件选项权重掷骰。玩家写成几套固定打法，每套一个情景：例如“追随郑氏并改法、照顾三省”“忠于明室、肯放属国”“忠于明室、不放远南”。玩家打法要合理，不能替玩家做明显吃亏的选择（反例：让忠于明室的玩家照准吕宋请饷）。
3. **参数扫描。** 同一个数取三四档，列成表交给作者挑，不自己拍板：系数 8/10/12，吴本部按 1/2、1/3、1/4、0 计，每月摆动 −1、−1.5、−2、−3。
4. **对照作者的目标逐项列分布。** 作者给的目标（例如“三家同时反吴 95–99%”“南洋宣慰司拥吴约 80%”）每条一行，达不到就提出改法；数值改动先问作者。
5. **外部数据取自存档，写明出处。** 例如国力权重用某个存档里的 GDP、陆军营数；取不到的项写明按 0 或按假设计。
6. **规则一改就重跑，旧结果标作废。** 模型漏一条规则，结论就会错：属国的自主等级只有两级、让权不能无限提级；承诺先满时拥明的海外属国可以选中立。每次改脚本都重跑全部情景。
7. **必要时附图。** 比较几个参数下某个量的走势，用折线图，横轴月份。

交付时写清：跑了多少局、哪些是假设、模拟里的“玩家”是固定打法，实机比例会有出入。模拟结果是设计估算，不是引擎验证。
